# ASDM Demo Builder 介绍

欢迎使用 ASDM Demo Builder 工具集，这是一个强大的演示站点生成工具。

## 什么是 ASDM？

ASDM 是一个用于构建AI辅助开发工具的框架。它提供了一套完整的工具集生态系统，帮助开发者更高效地构建和管理项目。

### 核心特性

- **模块化设计**：每个工具集都是独立的模块
- **可扩展性**：易于添加新功能和新工具集
- **标准化**：统一的接口和规范

## Demo Builder 功能

### 自动页面生成

Demo Builder 能够自动将 Markdown 文件转换为交互式演示站点。每个一级标题都会成为一个独立的演示页面。

### 导航控制

支持键盘导航和触摸手势，让演示更加流畅。

- **左箭头**：上一页
- **右箭头**：下一页  
- **空格键**：快速翻页

### 全屏模式

点击播放按钮即可进入全屏演示模式，专注于内容展示。

## 使用方法

### 基本用法

使用以下命令创建演示站点：

```bash
/asdm-build-demo ./README.md
```

### 高级选项

```bash
# 自定义输出目录和标题
/asdm-build-demo presentation.md -o my-demo -t "我的演示"
```

## 技术架构

### 前端技术栈

Demo Builder 使用现代 Web 技术构建：

- **HTML5**：语义化标记
- **CSS3**：响应式设计和动画
- **JavaScript**：交互功能

### 构建流程

1. **解析 Markdown**：提取标题结构和内容
2. **生成 HTML**：基于模板创建页面
3. **样式应用**：添加响应式样式
4. **功能集成**：嵌入交互脚本

## 最佳实践

### 内容组织

为了获得最佳的演示效果，建议按照以下方式组织内容：

- 使用清晰的标题层级
- 保持段落简洁明了
- 适当使用代码块和列表

### 性能优化

- 压缩图片资源
- 最小化 CSS 和 JavaScript
- 使用 CDN 加速

## 扩展功能

### 自定义主题

Demo Builder 支持主题定制，可以根据需要修改样式文件。

### 插件系统

未来版本计划支持插件系统，允许扩展更多功能。

## 常见问题

### 支持哪些 Markdown 语法？

支持标准的 Markdown 语法，包括：

- 标题（#, ##, ###）
- 粗体、斜体
- 代码块
- 链接和图片
- 列表

### 如何添加自定义样式？

可以修改 `demo-styles.css` 文件来自定义样式。
