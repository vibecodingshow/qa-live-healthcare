# 演示站点规格

## 语言指南

此演示站点规范必须使用环境检测到的响应语言。确保文档中的所有内容遵循：

1. **语言一致性**：在整个文档中使用相同的语言
2. **写作规范**：遵循检测到语言的写作风格和格式
3. **清晰性**：确保所选语言中的内容清晰易懂

**支持的语言**：
- 英文 (en)
- 中文 (zh)
- 根据环境检测的其他语言

---

## 概述

本规范定义了演示站点的结构和功能要求。此类站点用于从 Markdown 文档生成交互式演示，支持全屏播放和键盘导航。

**主要用途**：
- 产品演示和展示
- 技术文档演示
- 培训材料展示
- 项目汇报演示

---

## 站点结构

使用以下模板结构 when generating 演示站点：

```markdown
# 演示站点结构规范

**站点根目录**: ./demo-output/

## 1. 文件结构

```
demo-output/
├── index.html              # 首页和导航页
├── pages/                  # 演示页面目录
│   ├── page1.html         # 第1个页面
│   ├── page2.html         # 第2个页面
│   └── ...
├── assets/                # 静态资源目录
│   ├── css/               # 样式文件
│   │   ├── styles.css     # 主样式文件
│   │   └── themes/        # 主题样式
│   ├── js/                # JavaScript 文件
│   │   ├── main.js        # 主逻辑文件
│   │   ├── navigation.js  # 导航功能
│   │   └── player.js      # 播放功能
│   └── images/            # 图片资源
└── config.json            # 站点配置文件
```

**关键元素**：
- 首页：包含播放按钮和页面导航
- 演示页面：基于 Markdown 一级标题生成
- 样式文件：支持响应式设计
- 配置文件：存储站点设置和主题配置

## 功能规格

### 导航功能指南

**重要**：
- 支持键盘左右箭头键切换页面
- 提供进度指示器和页面导航栏
- 支持触摸设备的手势导航

**示例功能**：
```javascript
// 键盘导航实现
document.addEventListener('keydown', (e) => {
    if (e.key === 'ArrowLeft') goToPreviousPage();
    if (e.key === 'ArrowRight') goToNextPage();
});
```

### 播放功能指南

**重要**：
- 播放按钮触发全屏演示模式
- 支持 ESC 键退出全屏
- 全屏模式下隐藏导航控件
- 显示当前播放进度

**示例功能**：
```javascript
// 全屏播放实现
function enterPresentationMode() {
    document.documentElement.requestFullscreen();
    hideNavigationControls();
    showPresentationProgress();
}
```

### 响应式设计指南

**重要**：
- 支持桌面、平板、手机等设备
- 自适应不同屏幕尺寸
- 保持内容可读性和可用性

当生成演示站点时：

1. **步骤 1**：解析 Markdown 文件结构

3. **步骤 3**：配置导航和播放功能

**重要**：
