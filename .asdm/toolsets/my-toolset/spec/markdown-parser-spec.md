# Markdown 解析器规格

## 语言指南

此 Markdown 解析器规范必须使用环境检测到的响应语言。确保文档中的所有内容遵循：

1. **语言一致性**：在整个文档中使用相同的语言
2. **写作规范**：遵循检测到语言的写作风格和格式
3. **清晰性**：确保所选语言中的内容清晰易懂

**支持的语言**：
- 英文 (en)
- 中文 (zh)
- 根据环境检测的其他语言

---

## 概述

本规范定义了 Markdown 文档到演示站点的转换规则。此解析器用于将 Markdown 标题结构转换为演示页面，并保留格式和内容层次。

**主要用途**：
- 将文档结构转换为演示页面
- 保持内容层次和格式
- 支持代码块和特殊格式
- 生成交互式导航结构

---

## 解析规则

使用以下转换规则 when parsing Markdown 文档：

```markdown
# Markdown 到 HTML 转换规范

## 1. 标题级别映射

| Markdown 标题 | HTML 结构 | 演示页面角色 |
|--------------|-----------|-------------|
| # 一级标题   | <h1>      | 独立页面    |
| ## 二级标题  | <h2>      | 页面主内容  |
| ### 三级标题 | <h3>      | 子节内容    |

## 2. 内容处理规则

- **段落**：转换为 <p> 标签
- **代码块**：转换为 <pre><code> 标签，保留语法高亮
- **列表**：转换为 <ul>/<ol> 和 <li> 标签
- **链接**：转换为 <a> 标签，保留目标属性
- **图片**：转换为 <img> 标签，处理相对路径
- **表格**：转换为 <table> 标签，保留样式

**关键元素**：
- 页面分割：基于一级标题
- 内容层次：基于标题级别
- 格式保留：支持 Markdown 扩展语法
- 资源处理：正确处理相对路径资源

---

## 页面生成指南

### 一级标题处理指南

**重要**：
- 每个一级标题生成一个独立的 HTML 页面
- 页面标题使用一级标题内容
- 页面 URL 使用标题的 slug 格式

**示例转换**：
```markdown
# 产品概述

转换为：
<!-- 生成 pages/product-overview.html -->
<h1>产品概述</h1>
```

### 二级标题处理指南

**重要**：
- 二级标题作为页面的主要内容章节
- 保持与上级标题的层次关系
- 支持嵌套内容结构

**示例转换**：
```markdown
## 核心功能

转换为：
<section class="content-section">
    <h2>核心功能</h2>
    <!-- 后续内容 -->
</section>
```

### 特殊格式处理指南

**重要**：
- 代码块支持语法高亮
- 数学公式支持 LaTeX 渲染
- 表格支持响应式设计
- 图片支持懒加载

## 使用指南

当解析 Markdown 文档时：

3. **步骤 3**：分割内容到不同页面
4. **步骤 4**：转换 Markdown 格式为 HTML

**重要**：
- 保持原始文档的语义结构
- 正确处理嵌套的列表和代码块
- 确保资源路径的正确转换

**示例**：
