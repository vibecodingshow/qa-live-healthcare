# 主题模板规格

## 语言指南

此主题模板规范必须使用环境检测到的响应语言。确保文档中的所有内容遵循：

1. **语言一致性**：在整个文档中使用相同的语言
2. **写作规范**：遵循检测到语言的写作风格和格式
3. **清晰性**：确保所选语言中的内容清晰易懂

**支持的语言**：
- 英文 (en)
- 中文 (zh)
- 根据环境检测的其他语言

---

## 概述

本规范定义了演示站点主题的自定义模板和配置规则。此模板系统允许用户定制站点的视觉样式、布局和交互行为。

**主要用途**：
- 定义主题颜色和字体配置
- 配置布局和间距设置
- 自定义播放行为和动画效果
- 支持多主题切换和管理

---

## 主题结构

使用以下模板结构 when generating 主题配置：

```markdown
# 主题配置规范

## 1. 主题配置文件结构

```json
{
  "theme": {
    "name": "默认主题",
    "version": "1.0.0",
    "author": "演示站点构建器"
  },
  "colors": {
    "primary": "#2c3e50",
    "secondary": "#3498db",
    "background": "#ffffff",
    "text": "#333333"
  },
  "typography": {
    "fontFamily": "Arial, sans-serif",
    "fontSize": "16px",
    "lineHeight": "1.6"
  },
  "layout": {
    "maxWidth": "1200px",
    "spacing": "20px",
    "breakpoints": {
      "mobile": "768px",
      "tablet": "1024px"
    }
  },
  "animations": {
    "pageTransition": "slide",
    "duration": "0.3s"
  }
}
```

**关键元素**：
- 颜色配置：定义品牌色彩和配色方案
- 字体配置：定义字体家族和排版设置
- 布局配置：定义响应式布局参数
- 动画配置：定义过渡效果和行为

## 主题配置指南

### 颜色配置指南

**重要**：
- 提供完整的颜色调色板
- 支持亮色和暗色主题
- 确保颜色对比度符合可访问性标准

**示例配置**：
```css
:root {
  --primary-color: #2c3e50;
  --secondary-color: #3498db;
  --background-color: #ffffff;
  --text-color: #333333;
}
```

### 字体配置指南

**重要**：
- 支持系统字体和网络字体
- 定义字体大小层次结构
- 确保字体可读性和加载性能

**示例配置**：
```css
:root {
  --font-family: 'Inter', Arial, sans-serif;
  --font-size-base: 16px;
  --font-size-large: 24px;
  --font-size-small: 14px;
}
```

### 布局配置指南

**重要**：
- 定义响应式断点
- 配置间距和边距系统
- 支持网格和弹性布局

**示例配置**：
```css
:root {
  --container-max-width: 1200px;
  --spacing-unit: 20px;
  --breakpoint-mobile: 768px;
  --breakpoint-tablet: 1024px;
}
```

## 使用指南

当自定义主题时：

1. **步骤 1**：选择基础主题模板
2. **步骤 2**：配置颜色和字体设置
3. **步骤 3**：调整布局和间距
4. **步骤 4**：预览并应用主题

**重要**：
- 确保主题在不同设备上的一致性
- 测试颜色对比度和可访问性
- 验证主题配置的兼容性

## 输出格式

主题配置应该输出为：

**格式**：JSON 配置文件和 CSS 变量
**位置**：./demo-output/assets/css/themes/ 目录
**命名**：基于主题名称的命名约定

**格式细节**：
- JSON 配置文件存储主题设置
- CSS 变量文件定义样式变量
- 支持主题包的导入和导出

**示例**：
- 示例输出路径：`./demo-output/assets/css/themes/default.json`
- 示例命名：`{theme-name}.json`
