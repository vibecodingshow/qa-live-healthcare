# Instructions for asdm-preview-demo action

## Purpose
此指令指导 AI 模型预览已构建的演示站点。它启动本地开发服务器，允许用户在浏览器中实时预览演示效果，并支持热重载功能。

## Language Detection

在生成任何文件之前，您必须检测并使用当前环境的响应语言：

1. **检测响应语言**：分析环境设置以确定主要语言
2. **应用语言一致性**：确保所有生成的文件使用检测到的语言
3. **支持的语言**：中文 (zh)

## Context Injection

在预览演示站点之前，AI 模型应检查相关文件：

1. **演示站点配置**：`demo-output/config.json`
2. **构建报告**：`demo-output/build-report.md`
3. **站点结构**：检查 demo-output 目录完整性

## Steps to Preview Demo Site

### 1. 检查演示站点存在性

验证演示站点是否已构建：
- 检查 demo-output 目录是否存在
- 验证 index.html 文件是否存在
- 确认所有必要的资源文件完整

### 2. 选择预览方式

根据环境配置选择合适的预览方式：
- **本地开发服务器**（推荐）：启动 HTTP 服务器
- **文件系统预览**：直接打开 HTML 文件
- **集成 IDE 预览**：使用 IDE 内置预览功能

### 3. 启动本地开发服务器

配置并启动本地服务器：
- 使用 Python 的 `http.server` 模块
- 或使用 Node.js 的 `http-server` 包
- 配置端口号（默认：8080）
- 启用目录列表和 CORS 支持

### 4. 配置热重载功能

设置文件监视和自动刷新：
- 监视 HTML、CSS、JS 文件变化
- 自动刷新浏览器预览
- 支持实时编辑和预览

### 5. 打开浏览器预览

自动在浏览器中打开演示站点：
- 生成预览 URL（如：http://localhost:8080）
- 使用系统默认浏览器打开
- 或在 IDE 内置浏览器中预览

### 6. 测试交互功能

验证所有交互功能正常工作：
- 播放按钮和全屏功能
- 键盘导航（左右键切换）
- 响应式设计适配
- 页面切换流畅性

### 7. 提供预览说明

生成预览使用说明：
- 键盘快捷键说明
- 导航方式说明
- 自定义配置选项
- 故障排除指南

### 8. 监控预览状态

持续监控预览过程：
- 显示服务器运行状态
- 监控文件变化和重载
- 提供停止预览的指令

## Execution Guidelines

### When to Use This Action

使用此动作时：
- 需要实时预览演示站点效果
- 需要测试交互功能和响应式设计
- 需要进行样式和内容调整

### 预览环境要求

- 本地环境需要支持 HTTP 服务器
- 浏览器需要支持现代 JavaScript 功能
- 建议使用最新版本的浏览器

### 键盘导航功能

验证键盘导航功能：
- 左箭头键：切换到上一页
- 右箭头键：切换到下一页
- 确保页面切换流畅无卡顿

### 安全注意事项

- 仅在本地环境中预览
- 避免在生产环境中使用开发服务器
- 注意文件权限和访问控制

## Usage

要使用此指令，AI 模型应：
1. 检测响应语言
2. 检查演示站点完整性
3. 选择合适的预览方式
4. 启动开发服务器
5. 打开浏览器预览
6. 测试交互功能
7. 提供使用说明

## Output Summary

完成动作后，将提供以下功能：
- 运行中的本地开发服务器
- 浏览器中的实时预览
- 热重载和文件监视
- 交互功能测试报告
- 预览使用说明文档
