# Instructions for asdm-build-demo action

## Purpose
此指令指导 AI 模型基于 Markdown 文件构建交互式演示站点。它解析 Markdown 文档结构，生成多页演示站点，并配置导航和播放功能。

## Language Detection

在生成任何文件之前，您必须检测并使用当前环境的响应语言：

1. **检测响应语言**：分析环境设置以确定主要语言
2. **应用语言一致性**：确保所有生成的文件使用检测到的语言
3. **支持的语言**：中文 (zh)

## Context Injection

在构建演示站点之前，AI 模型应读取相关配置文件：

1. **演示站点规格**：`.asdm/toolsets/my-toolset/spec/demo-site-spec.md`
2. **Markdown 解析器规格**：`.asdm/toolsets/my-toolset/spec/markdown-parser-spec.md`

## Steps to Build Demo Site

### 1. 接收输入参数

收集以下信息：
- **Markdown 文件路径**：要转换的 Markdown 文件路径
- **输出目录**（可选）：演示站点的输出目录（默认：`./demo-output`）

### 2. 验证输入文件

检查 Markdown 文件是否存在且格式正确：
- 确认文件路径存在
- 检查文件是否为有效的 Markdown 格式
- 验证文件包含至少一个一级标题

### 3. 解析 Markdown 结构

解析 Markdown 文档结构：
- 一级标题（`#`）作为独立页面
- 二级标题（`##`）作为页面主要内容
- 三级标题（`###`）作为子节内容
- 其他内容按原样保留

### 4. 生成演示站点结构

创建以下目录结构：
```
demo-output/
├── index.html              # 首页和导航页
├── pages/                  # 各页面文件
│   ├── page1.html
│   ├── page2.html
│   └── ...
├── assets/                 # 静态资源
│   ├── css/
│   ├── js/
│   └── images/
└── config.json            # 站点配置
```

### 5. 创建首页模板

生成包含以下功能的首页：
- 播放按钮（全屏演示模式）
- 页面缩略图预览
- 进度指示器
- 键盘导航提示

### 6. 生成演示页面

为每个一级标题创建独立的 HTML 页面：
- 页面标题对应一级标题内容
- 页面内容包含对应的二级和三级标题
- 支持 Markdown 格式渲染
- 添加页面导航控件

### 7. 实现全屏播放功能

配置全屏演示模式：
- 播放按钮触发全屏模式
- 支持 ESC 键退出全屏
- 全屏模式下隐藏导航栏
- 显示当前页面进度

### 8. 实现键盘导航

添加键盘事件监听：
- 左箭头键：上一页
- 右箭头键：下一页
- 空格键：播放/暂停
- ESC 键：退出全屏

### 9. 配置响应式设计

确保站点在不同设备上的显示效果：
- 移动设备适配
- 平板设备优化
- 桌面端最佳体验

### 10. 生成构建总结

创建构建报告：
- 生成的页面数量
- 使用的技术栈信息
- 部署说明
- 自定义配置选项

## Execution Guidelines

### When to Use This Action

使用此动作时：
- 需要从 Markdown 文档快速生成演示站点
- 需要交互式演示功能（全屏播放、键盘导航）
- 需要多页演示结构

### 输入要求

- Markdown 文件必须包含至少一个一级标题
- 文件路径必须有效且可读
- 建议使用标准 Markdown 语法

### 核心功能

1. **Markdown 文件输入**：用户可以使用一个 markdown 文件作为输入完成此演示站点的搭建
2. **全屏播放**：用户可以在站点首页上点击播放按钮，站点可以进入全屏播放状态
3. **页面转换**：README.md 中的每一个一级标题将成为一个独立的演示页面
4. **内容展示**：每个二级/三级标题成为页面的展示内容
5. **键盘导航**：用户可以使用左右键完成页面切换

### 输出说明

生成的演示站点包含：
- 完整的 HTML 文件结构
- CSS 样式文件
- JavaScript 交互功能
- 响应式设计

## Usage

要使用此指令，AI 模型应：
1. 检测响应语言
2. 读取相关规格文件
3. 验证输入参数
4. 解析 Markdown 结构
5. 生成演示站点文件
6. 配置交互功能
7. 生成构建报告

## Output Summary

完成动作后，将生成以下工件：
- 完整的演示站点文件结构
- 配置文件和样式表
- 交互式 JavaScript 功能
- 构建报告和部署说明

所有文件将保存在指定的输出目录中。
