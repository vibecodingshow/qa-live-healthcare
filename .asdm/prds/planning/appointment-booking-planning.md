## 1. 产品愿景

预约挂号功能旨在为医疗问诊平台打造一个便捷、高效的在线预约就诊系统，让患者能够通过手机或网页随时随地预约医生的线下门诊，告别传统排队挂号的烦恼。

**核心价值主张：**
- **患者端**：节省时间、提升就医体验、减少等待焦虑
- **医生端**：合理安排工作时间、提高接诊效率、优化患者分流
- **平台端**：增强用户粘性、提升医疗服务能力、积累医疗数据

**最终愿景：**
打造一个连接患者与医生的智能预约平台，实现医疗资源的优化配置，让每一位患者都能享受到便捷、有序的预约就诊服务。

## 2. 产品概述

### 2.1 产品描述

预约挂号功能是一个面向患者和医生的在线预约管理系统，患者可以通过平台查看医生的排班信息、选择合适的就诊时间、完成预约操作；医生可以管理自己的门诊排班、查看预约患者列表、处理预约事务。

### 2.2 解决的问题

| 问题 | 当前痛点 | 解决方案 |
|------|---------|---------|
| 排队时间长 | 患者需要在医院现场长时间排队等候 | 在线预约，随时查看排队情况 |
| 预约困难 | 电话预约成功率低、沟通成本高 | 透明化的线上预约系统 |
| 信息不透明 | 无法提前了解医生排班和余号情况 | 实时展示排班和号源信息 |
| 临时变动 | 行程变化无法及时取消预约 | 支持线上取消和修改预约 |
| 资源浪费 | 患者爽约导致医疗资源浪费 | 诚信机制和候补机制 |

### 4.2 需求详细说明

#### REQ-001 医生排班展示

**功能描述：**
- 患者进入预约挂号页面，可按科室、医生姓名搜索
- 展示医生的基本信息：姓名、职称、科室、头像、简介
- 展示医生近期排班：日期、时段（上午/下午/晚上）、可预约状态
- 支持日历视图和列表视图切换

**业务规则：**
- 只展示有排班的医生
- 排班信息实时更新
- 过期排班自动隐藏

#### REQ-002 号源查询

**功能描述：**
- 每个时段显示剩余可预约数量
- 颜色区分：绿色（有号）、黄色（紧张）、红色（已满）
- 点击具体时段显示余号详情

**业务规则：**
- 余号数量实时更新
- 预约成功后立即扣减余号
- 取消预约后释放余号

#### REQ-003 预约选择

**功能描述：**
- 患者选择医生后进入预约流程
- 选择就诊日期（展示可预约日期）
- 选择就诊时段（上午/下午/晚上）
- 选择具体的时间点（如 9:00-9:30）
- 选择就诊人（本人或帮家人预约）
- 填写简要病情描述（选填）

**业务规则：**
- 只能选择未来14天内的日期
- 每个时段每人只能预约一次
- 同一时段同一医生不能重复预约

#### REQ-004 预约确认

**功能描述：**
- 患者提交预约后，系统进行号源校验
- 校验通过后创建预约记录
- 向患者展示预约成功信息，包括：预约号、取号密码、就诊时间、就诊地点、注意事项

**业务规则：**
- 使用分布式锁防止超卖
- 预约成功后发送短信/推送通知
- 生成唯一预约编号

#### REQ-008 排班管理

**功能描述：**
- 医生登录后进入排班管理页面
- 可设置常规排班模板（每周几出诊）
- 可临时调整某天的排班（停诊/加诊）
- 可设置每个时段的最大号源数
- 可设置每个患者的接诊时长

**业务规则：**
- 排班需提前24小时设置
- 停诊需通知已预约患者
- 最大号源数不能超过医生承受能力

## 6. 业务流程

### 6.1 患者预约流程

```
开始
  ↓
搜索/选择科室 → 选择医生 → 查看排班
  ↓
选择就诊日期 → 选择时段 → 选择就诊人
  ↓
填写病情描述（选填） → 确认预约信息
  ↓
提交预约 → 号源校验 → 预约成功
  ↓
发送通知 → 记录预约 → 完成
```

### 6.2 医生排班流程

```
开始
  ↓
登录系统 → 进入排班管理
  ↓
查看当前排班 → 添加/修改排班
  ↓
设置号源数量 → 设置接诊时间
  ↓
保存排班 → 排班生效 → 通知患者（如有调整）
```
