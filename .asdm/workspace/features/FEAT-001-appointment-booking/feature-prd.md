# Feature PRD: 预约挂号功能

**Feature ID**: FEAT-001-appointment-booking
**Created Date**: 2026-04-29
**Status**: PLANNED
**Language**: 中文 (zh)

---

## 1. 概述

### 1.1 功能摘要

- **功能描述**: 为 QA Live Healthcare 医疗问诊平台添加"预约挂号"功能模块，允许患者在线预约医生的线下门诊号。
- **需求背景**: 当前平台仅支持在线问诊，患者无法预约线下门诊。线下门诊是医疗服务的重要场景，需要提供便捷的线上预约渠道。
- **受益用户**: 需要就诊的患者、管理排班的医生

### 1.2 目标

- **目标 1**: 实现患者端完整的预约挂号流程（浏览医生排班 → 选择时段 → 提交预约 → 查看预约记录）
- **目标 2**: 实现医生端查看和管理自己的预约列表
- **目标 3**: 支持预约状态流转：待确认 → 已确认 → 已取消 → 已完成
- **目标 4**: 与现有患者/医生身份认证系统无缝集成

## 2. 用户故事

### Story 1: 浏览医生排班表

**作为** 患者
**我希望** 能够在医生详情页面查看该医生的门诊排班信息
**以便** 了解医生的出诊时间并选择合适的时段进行预约

**验收标准**:
- [ ] 显示医生一周内的排班时段（日期 + 时段 + 剩余号源）
- [ ] 区分"已满"、"可预约"、"已过时"三种状态
- [ ] 支持切换查看不同周次的排班
- [ ] 移动端友好展示

### Story 2: 提交预约申请

**作为** 患者
**我希望** 能够选择具体时段并提交预约申请
**以便** 成功预约到医生的线下门诊号

**验收标准**:
- [ ] 选择日期和时段后显示预约确认弹窗
- [ ] 弹窗包含：医生信息、预约时间、就诊须知
- [ ] 可选填简要病情描述（不超过200字）
- [ ] 提交成功后显示预约凭证/回执
- [ ] 未登录患者需先完成身份验证

### Story 3: 管理我的预约

**作为** 患者
**我希望** 在个人中心能够查看和管理我的所有预约记录
**以便** 跟踪预约状态并在必要时取消预约

**验收标准**:
- [ ] 以列表形式展示所有预约记录（含历史）
- [ ] 显示每条记录的完整信息：医生、时间、状态
- [ ] 支持"待确认"状态的预约取消操作（需二次确认）
- [ ] 状态标签颜色区分（待确认=橙色，已确认=绿色，已取消=灰色，已完成=蓝色）

### Story 4: 医生查看预约列表

**作为** 医生
**我希望** 在诊室工作台中能查看患者的预约列表
**以便** 了解即将到来的预约安排并提前准备

**验收标准**:
- [ ] 工作台新增"预约管理"Tab 或入口
- [ ] 按日期分组展示预约列表（今日优先）
- [ ] 显示患者基本信息和病情简述
- [ ] 支持按状态筛选预约

## 4. 非功能性需求

### 4.1 性能
- 页面首次加载时间 < 2s（Mock 数据场景）
- 日历组件切换月份/周次无感知延迟

### 4.2 安全
- 仅已登录/验证的患者方可提交预约
- 取消预约需验证当前患者身份
- Mock 数据中不存储真实敏感信息

### 4.3 可扩展性
- 数据模型预留字段以支持后续真实 API 对接
- 组件设计考虑多科室、多院区扩展

### 4.4 可靠性
- 并发场景下号源不超卖（前端模拟锁机制）
- 异常状态有明确的用户提示

---

## 5. 技术要求

### 5.1 架构考量
- 遵循项目现有架构模式：View → Store → Mock Data
- 新增数据文件放置于 `src/data/` 目录
- 复用现有 `store/index.ts` 的 reactive store 模式
- UI 组件优先使用 Ant Design Vue 内置组件（`a-calendar`, `a-table`, `a-card`, `a-modal` 等）

### 5.2 依赖关系
- **内部依赖**: 依赖现有 Patient / Doctor 数据模型和身份验证逻辑
- **外部依赖**: dayjs（已有）用于日期处理；Ant Design Vue（已有）用于 UI

### 5.3 约束条件
- 纯前端实现，使用 Mock 数据驱动
- 不涉及后端接口对接
- 保持与现有代码风格一致（`<script setup lang="ts">`, scoped CSS）

## 8. 实施备注

- 排班数据建议使用固定的未来 2 周排期模板循环生成
- 预约状态机：`PENDING`(待确认) → `CONFIRMED`(已确认) / `CANCELLED`(已取消) → `COMPLETED`(已完成)
- 日历组件使用 Ant Design Vue 的 Calendar 组件或自定义面板
- 导航栏"预约挂号"链接指向新页面 `/appointment`
- 考虑在 Doctors.vue 医生卡片上增加"立即预约"快捷按钮
