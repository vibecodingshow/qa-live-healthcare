## 4. 测试用例

### 4.1 预约流程测试用例

```

用例名称: 成功预约完整流程
前置条件: 系统正常运行，有可预约医生
测试步骤:
  1. 访问 /appointment
  2. 选择一个医生点击预约
  3. 选择可预约日期
  4. 选择上午/下午时段
  5. 填写姓名、手机号
  6. 点击确认预约
预期结果:
  - 预约成功提示
  - 显示预约号
  - 可在订单页查询到
```
