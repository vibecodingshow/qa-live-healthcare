## 2. 详细需求

### 2.1 功能需求
- 组件 Props:
  - `doctorId: string`（必填）— 目标医生 ID
  - `modelValue?: ScheduleSlot | null`（可选）— v-model 双向绑定当前选中时段
- 日历展示:
  - 以周为单位展示 7 天的排班概况
  - 每天下方列出当天的可用时段（上午/下午）
  - 每个时段显示: 时间范围、剩余号源数、状态标签
  - 支持上一周/下一周切换按钮
- 时段状态视觉区分:
  - `可预约`: 绿色边框，显示剩余号源（如 "剩余 15/20"）
  - `已满`: 灰色背景 + "已满"标签，不可点击
  - `已过时`: 半透明灰色，不可点击
- 交互:
  - 点击可选时段触发选中高亮
  - 选中变化时 emit `update:modelValue` 事件
  - 今天的日期用特殊标记突出

### 2.2 技术需求
- 使用 Ant Design Vue 的 `<a-calendar>` 或自定义网格布局
- 使用 dayjs 处理日期计算和比较
- 组件放置于 `src/components/ScheduleCalendar.vue`
- 使用 `<script setup lang="ts">` + scoped CSS

### 2.3 约束与限制
- 仅负责展示和选择，不处理预约提交逻辑（提交由 TASK-005 负责）
- 响应式适配: 桌面端 7 列网格，移动端单列堆叠

## 3. 实施方法

### 3.1 推荐方案
基于 Ant Design Vue 的 Card + Grid 自定义日历面板，不用内置 Calendar（定制性不足）。

### 3.2 实施步骤
1. 创建组件骨架 `src/components/ScheduleCalendar.vue`
2. 实现 Props 定义和 emits 声明
3. 实现周数据计算逻辑（根据 currentWeekOffset 计算 7 天日期范围）
4. 实现日历头部（星期标题 + 周切换按钮）
5. 实现每日排班渲染（遍历当天 slots，按状态着色）
6. 实现时段点击选中逻辑（v-model 双向绑定）
7. 添加响应式样式（@media 断点 768px）
8. 集成到 Appointment.vue 占位页面进行初步验证

**验证步骤**: `npx vue-tsc --noEmit` + `npm run dev` 手动验证组件渲染和交互。

### 3.3 技术考量
- 使用 `computed` 派发当前周的排班数据，避免重复计算
- 日期比较统一使用 dayjs 的 `isBefore()`, `isSame()`, `isAfter()`
- "今天"的判断基于 dayjs().format('YYYY-MM-DD')
- 周切换通过 ref `weekOffset` 控制（0=本周, 1=下周, -1=上周）

### 3.4 项目上下文引用
- `src/store/index.ts` — 调用 `getSchedulesByDoctor()` 获取数据
- TASK-002 的 Store 方法
- UI 设计规范: 渐变主题色、卡片圆角 12-16px、最大宽度 1200px
