## 4. 技术方案

### 4.1 表单设计

```typescript
interface PatientFormData {
  patientName: string;    // 患者姓名
  patientPhone: string;   // 患者手机号
}
```

### 4.2 验证规则

```typescript
const formRules = {
  patientName: [
    { required: true, message: '请输入姓名' },
    { min: 2, max: 20, message: '姓名长度为2-20个字符' }
  ],
  patientPhone: [
    { required: true, message: '请输入手机号' },
    { pattern: /^1[3-9]\d{9}$/, message: '请输入正确的手机号' }
  ]
};
```

### 4.3 数据流

```
用户填写表单 → 实时表单验证 → 数据暂存 localStorage
点击提交 → 完整验证 → 调 verifyPatient() 验证身份
验证通过 → 进入预约确认
验证失败 → 显示错误提示
```

### 4.4 复用现有逻辑

- 复用 `src/store/index.ts` 中的 `verifyPatient(name, birthday)` 方法
- 扩展支持手机号验证
