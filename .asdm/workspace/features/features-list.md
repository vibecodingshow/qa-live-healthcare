## Feature Details

### FEAT-001: appointment-booking

**Feature Name**: 预约挂号功能  
**Created Date**: 2026-04-21  
**Status**: PLANNED  
**Priority**: High

**Description**:
预约挂号功能允许患者在线预约医生的线下门诊时段，患者可以选择医生、日期和时间段，完成挂号预约，并查看预约记录。

**Objectives**:
- 扩展服务范围：从单一的在线问诊功能，扩展到线下门诊预约
- 提升用户体验：减少患者现场排队等候时间
- 优化资源调配：医生可管理自己的门诊排班
- 满足业务需求：支持患者预约医生的线下门诊服务

**User Stories**:
1. 患者预约门诊
2. 患者查看预约记录
3. 医生管理门诊排班
4. 医生查看预约患者
