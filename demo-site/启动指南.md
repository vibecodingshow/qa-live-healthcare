# 医疗面试系统演示站点启动指南

## 🚀 快速启动（推荐）

### Windows PowerShell用户
双击运行 `start.ps1` 文件，或者在PowerShell中运行：

```powershell
.\start.ps1
```

### Windows CMD用户
双击运行 `start.bat` 文件，或者在CMD中运行：

```cmd
start.bat
```

## 📋 手动启动步骤

### 1. 进入demo-site目录
```bash
cd demo-site
```

### 2. 安装依赖（首次运行）
```bash
npm install
```

### 3. 启动开发服务器
```bash
npm run dev
```

服务器将在 http://localhost:5173 启动。

## 🌐 访问站点

打开浏览器访问：**http://localhost:5173**

## 🎯 功能使用

### 首页功能
- 查看演示内容概览
- 点击"🚀 开始演示"按钮进入演示模式
- 点击"全屏模式"按钮进入全屏

### 演示模式功能
- 使用 **←** **→** 方向键切换页面
- 按 **F** 键进入/退出全屏
- 按 **ESC** 键退出全屏
- 点击页面指示器快速跳转
- 点击"返回首页"退出演示

## ❓ 常见问题

### 1. 端口被占用
如果5173端口被占用，Vite会自动尝试下一个可用端口。请留意终端输出的端口号。

### 2. 依赖安装失败
- 确保Node.js版本 >= 18
- 清除npm缓存：`npm cache clean --force`
- 重新安装：`rm -rf node_modules && npm install`

### 3. TypeScript错误
运行以下命令：
```bash
npm run build
```
查看具体错误信息。
