概述

ASDM Demo Builder 是一个专门用于将 Markdown 文件转换为交互式演示站点的工具集。它提供了以下核心功能：

主要功能

自动页面生成

每个 H1 标题成为一个独立的演示页面，支持多页演示结构。

交互式导航

支持键盘左右键切换页面，提供流畅的导航体验。

全屏演示模式

点击播放按钮进入全屏演示模式，适合正式演示场景。

响应式设计

适配桌面、平板和移动设备，确保在各种设备上都有良好的体验。

技术特性

  • 基于现代 Web 技术（HTML5、CSS3、JavaScript）
  • 支持 Markdown 标准语法和扩展语法
  • 提供主题定制和样式配置功能
  • 支持实时预览和热重载

适用场景

ASDM Demo Builder 适用于：

  • 产品演示和展示
  • 技术文档演示
  • 培训材料展示
  • 项目汇报演示
