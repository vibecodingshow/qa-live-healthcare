# Instructions for asdm-customize-demo action

## Purpose
此指令指导 AI 模型自定义演示站点的样式和配置。它允许用户修改主题颜色、字体、布局等视觉元素，以及配置播放行为和导航选项。

## Language Detection

在生成任何文件之前，您必须检测并使用当前环境的响应语言：

1. **检测响应语言**：分析环境设置以确定主要语言
2. **应用语言一致性**：确保所有生成的文件使用检测到的语言
3. **支持的语言**：中文 (zh)

## Context Injection

在自定义演示站点之前，AI 模型应读取相关配置文件：

1. **演示站点配置**：`demo-output/config.json`
2. **当前样式表**：`demo-output/assets/css/styles.css`
3. **主题模板**：`.asdm/toolsets/my-toolset/spec/theme-templates.md`

## Steps to Customize Demo Site

### 1. 收集自定义选项

提供可自定义的配置选项：

**主题选项**：
- 主色调和配色方案
- 字体家族和大小
- 背景样式和纹理
- 按钮和控件样式

**布局选项**：
- 页面边距和间距
- 导航栏位置和样式
- 内容区域布局
- 响应式断点配置

**播放行为选项**：
- 自动播放设置
- 页面切换动画
- 全屏模式配置
- 键盘快捷键自定义

### 2. 显示当前配置

展示当前的站点配置：
- 显示当前主题设置
- 展示布局预览
- 提供配置值编辑界面

### 3. 应用自定义设置

根据用户选择应用配置：

**CSS 样式更新**：
- 生成新的 CSS 变量
- 更新颜色和字体定义
- 应用布局调整
- 保存自定义样式表

**JavaScript 配置更新**：
- 更新播放行为配置
- 修改导航选项
- 调整动画效果
- 保存配置文件

### 4. 预览自定义效果

实时预览自定义效果：
- 启动预览服务器
- 应用临时样式更改
- 允许用户实时调整
- 提供撤销/重做功能

### 5. 生成主题包

创建可重用的主题包：
- 导出当前配置为主题包
- 生成主题配置文件
- 创建主题预览截图
- 打包主题资源文件

### 6. 配置主题切换

实现多主题支持：
- 创建主题选择界面
- 实现动态主题切换
- 保存用户主题偏好
- 提供默认主题选项

### 7. 验证自定义兼容性

确保自定义配置的兼容性：
- 测试响应式设计
- 验证浏览器兼容性
- 检查性能影响
- 确保功能完整性

### 8. 生成自定义报告

创建自定义配置报告：
- 列出所有修改的配置项
- 提供配置备份文件
- 生成部署说明
- 包含故障排除指南

## Execution Guidelines

### When to Use This Action

使用此动作时：
- 需要调整演示站点的视觉样式
- 需要配置播放行为和导航选项
- 需要创建自定义主题
- 需要适配特定品牌要求

### 自定义限制

- 确保自定义不影响核心功能
- 保持响应式设计的完整性
- 避免过度复杂的样式配置
- 确保浏览器兼容性

### 主题包管理

- 支持导入/导出主题包
- 提供主题包版本管理
- 允许主题包共享和重用

## Usage

要使用此指令，AI 模型应：
1. 检测响应语言
2. 读取当前配置和样式
3. 提供自定义选项界面
4. 应用用户自定义设置
5. 预览自定义效果
6. 生成主题包和配置
7. 验证兼容性和功能
8. 生成自定义报告

## Output Summary

完成动作后，将生成以下工件：
- 更新后的样式表和配置文件
- 自定义主题包（可选）
- 预览效果和配置报告
- 部署和备份文件

所有自定义配置将保存在演示站点目录中，并支持进一步的修改和扩展。
