# Vue 3 + TypeScript + Vite

医疗健康预约系统是基于 Vue 3 + TypeScript + Vite 构建的现代化单页应用，采用 Ant Design Vue 作为 UI 组件库。

# 核心特性

## 技术栈

| 技术 | 说明 | 版本 |
|------|------|------|
| Vue 3 | 渐进式 JavaScript 框架 | 3.4+ |
| TypeScript | 类型安全的 JavaScript 超集 | 5.0+ |
| Vite | 新一代前端构建工具 | 5.0+ |
| Ant Design Vue | 企业级 UI 组件库 | 4.x |

## 项目功能

- **医生预约** - 选择科室、医生、出诊时间
- **患者管理** - 添加和管理就诊人信息
- **预约记录** - 查看和管理历史预约
- **日历展示** - 可视化出诊时间表

# 开发指南

## 环境要求

- Node.js 18+ 
- npm 9+ 或 pnpm 8+

## 安装依赖

```bash
npm install
```

## 启动开发服务器

```bash
npm run dev
```

## 构建生产版本

```bash
npm run build
```

## 项目结构

```
src/
├── components/     # 公共组件
├── views/          # 页面组件
├── services/       # 业务服务
├── stores/         # 状态管理
├── types/          # TypeScript 类型
└── router/         # 路由配置
```

# 组件说明

## SlotCalendar 日历组件

用于展示医生的出诊时间，支持：
- 按日期选择可预约时段
- 显示已预约/已满状态
- 响应式布局适配

## AppointmentForm 表单组件

预约信息填写表单：
- 患者信息录入
- 科室和医生选择
- 出诊时间确认

## DoctorCard 医生卡片

展示医生信息：
- 头像和姓名
- 科室和职称
- 预约热度指标
